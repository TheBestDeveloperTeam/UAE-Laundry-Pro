# Lottie manifest-tier library

- **Masters:** `masters/master_000.json` … `master_099.json` (100 lightweight procedural loops).
- **Logical IDs:** 16,450+ entries in `lottie_manifest.json` (screen × role × variant × widget states).
- **Regenerate:** `dart run tool/generate_lottie_assets.dart` from repo root.

Masters are generated in-repo for size and licensing clarity. Replace individual masters with curated LottieFiles assets as needed; update the manifest `masters` map only.
