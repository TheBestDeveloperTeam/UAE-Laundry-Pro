# Change Request: POS Peripheral Framework Merge — LaundryPro UAE

**Change Request ID:** CR-2026-09-05-003  
**Date:** 2026-09-05  
**Requested By:** Magnificent Solution  
**Priority:** High  
**Status:** Approved — Implemented

---

## 1. Summary

Merges the standalone POS peripheral framework into `lib/peripherals/` under package `laundrypro_uae`. Adds Riverpod bootstrap alongside existing Provider auth, hardware ESC/POS printing via Windows spooler, keyboard-wedge scanner, cash drawer pulse, and an admin Peripherals console under Settings.

---

## 2. Scope

| Component | Deliverable |
|-----------|-------------|
| Core | `lib/peripherals/core/**` — printer, scanner, scale, cash drawer, remote SQL, SQLite storage |
| Bootstrap | `lib/peripherals/bootstrap.dart` — `bootstrapPeripherals()`, DB `laundrypro_peripherals.db` |
| Bridge | `lib/services/peripheral_print_service.dart` — `ReceiptModel`/order → `PosReceiptBuilder` → `PrinterManager` |
| POS | Hardware print, PDF fallback, scanner wedge, cash drawer on cash pay |
| Admin | `PeripheralsScreen` at `/settings/peripherals` |
| Tests | `test/peripherals/**` + `peripheral_print_service_test.dart` |
