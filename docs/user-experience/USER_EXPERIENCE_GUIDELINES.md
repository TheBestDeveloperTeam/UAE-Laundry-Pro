# User Experience (UX) Architecture & Ergonomic Standards
**Core Philosophy:** 0-Friction Human POS Ergonomics + UAE Cultural Prestige

---

## 1. Frictionless Cashier Interaction Principles
1. **Keyboard-First Workflow:** Every primary action has a dedicated function key (`F1` for customer search, `F2` for pay/confirm, `F5` for catalog reload, `Ctrl+K` for global search). Cashiers can complete a walk-in intake without touching a mouse.
2. **Instant Feedback:** Touch actions provide immediate visual ripple feedback, kinetic elevation, and audio/haptic confirmation.
3. **Zero Modal Lockout:** Non-modal sheets and easily dismissable overlays (`ESC` key) ensure the cashier never gets trapped in unexpected UI loops during peak morning/evening rushes.

---

## 2. Touch Screen & POS Terminal Ergonomics
- **Minimum Tap Target:** $48 \times 48\text{ px}$ on all interactive buttons, steppers, and filter chips.
- **Thumb Reach Zones:** Primary checkout and payment buttons anchored to the bottom-right (LTR) / bottom-left (RTL) for single-hand touch operation on $1024 \times 768$ touch displays.
- **Dual Scroll Physics:** Touch-aware scrolling with dual scrollbars preventing scrollbar jumping during dense order review.
