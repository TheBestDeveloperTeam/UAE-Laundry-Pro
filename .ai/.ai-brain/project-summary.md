# Project Summary

LaundryPro UAE is an offline-first Windows desktop laundry management system.

- Frontend: Flutter (Provider, MVVM, go_router)
- Backend: Plain PHP 8.x REST API (no framework, no Composer packages)
- Database: MySQL/MariaDB (`laundrypro`)
- Auth: JWT access + refresh tokens + RBAC permissions

**Live roadmap:** [complete-full-and-final-live-updated-development-roadmap.md](../marketing/03-technical/complete-full-and-final-live-updated-development-roadmap.md)

**Current phase:** Phase 1A–1C (schema, CRM, catalog, sales, sync parallel, license, backup)

Default dev admin: `admin` / `admin123` (change in production).
